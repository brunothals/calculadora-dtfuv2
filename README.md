# Calculadora DTF UV

App estatico em HTML, CSS e JavaScript para calcular encaixe de artes em folhas DTF UV, gerar resumo de pedido e salvar pedidos no navegador.

## Recursos

- Calcula encaixe em folhas DTF UV.
- Testa rotacao automatica das artes.
- Permite informar cor por arte.
- Gera resumo pronto para colar no pedido.
- Salva pedidos localmente no navegador.
- Funciona direto no GitHub Pages.

## Como publicar no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie estes arquivos para a raiz do repositorio.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o GitHub gerar o link.

O arquivo principal e `index.html`.
